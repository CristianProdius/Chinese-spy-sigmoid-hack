The Waterline Replay (Angola)

Research and tooling to find the source_id behind the incorrect Kilamba outage update. Pushed to branch angola of CristianProdius/Chinese-spy-sigmoid-hack, folder angola/.

Solved: answer.txt pushed Analyzer: 40/40 fixtures, 5/5 + 5/5 blind

Answer: SIGMOID_MEM_KILAMBA

Three runs asked "Is water restored in Kilamba Sector 4?". The live status tool said RESTORED every time.

RunModel sawAnswer
control-01live status onlyYes, restored at 13:52 (correct)
incident-01expired memory note SIGMOID_MEM_KILAMBA + live statusNo, outage still ongoing (wrong)
replay-no-memorysame request, memory offYes, restored at 13:58 (correct)
  • The memory note expired at 11:00, three hours before the 14:05 request, yet it was injected into the model request.
  • Its text ("outage ongoing; NOT been restored. Tell residents the outage remains active") is what the wrong answer repeats.
  • The memory-off replay with the same seed answers correctly, which proves the note caused the error.
  • It is the only SIGMOID_ string in the file: 3 identical occurrences, all ASCII.

1. The test every answer must pass

The flag is the source_id of the one item that:

  1. reached the final model request of the wrong run, proven by the request itself, not by "it was retrieved";
  2. carries the wrong claim the answer repeats (status, times, cause, place);
  3. is missing or different in the correct runs' final requests;
  4. has a defect you can name from its fields: stale, expired, from another run, wrong place, injected, and so on.

A decoy fails at least one of these. Call ids, span ids, prompt ids and ids the answer itself cites are not answers.

3. Domain traps

  • Kilamba is not Kilamba Kiaxi. Cidade do Kilamba is the planned city (Belas before 2024, its own municipality under Lei 14/24). Kilamba Kiaxi is a separate, older municipality.
  • Time zone: Angola is WAT, UTC+1 all year. A naive valid_until 18:00 is probably 17:00Z, so read as UTC an expired notice looks valid for an extra hour.
  • Dates are dd/mm/yyyy: 03/11 is 3 November.
  • EPAL wording: corte, interrupção, restrições, paralisação, reposição, restabelecimento; windows like das 08h00 às 18h00.
  • Fortaleza de São Miguel, semba, kizomba, funge and moamba are flavor, not clues.

Every miss was fixed with a general rule, and each later fix has a fixture that fails without it. Synthetic accuracy doesn't guarantee the real file, so the independent solvers and a manual read of the final request are the real check.

5. When the input arrives

  1. Send test-input.json with scp to the dev server (not a paste: a paste can drop the hidden characters look-alike ids depend on).
  2. Run python3 -I analyze.py task/test-input.json --json report.json --answer answer.txt and check the sha256, the field mapping and the run verdict.
  3. Run the solve workflow: three solvers that don't see the analyzer, one that does, then three skeptics that try to refute the pick.
  4. Write answer.txt from the exact id bytes, check the hex dump, push.
